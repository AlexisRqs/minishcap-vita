# Bundled Port Menu v0.3.0

Sources in `platform/vita/port-menu` are an unchanged copy of revision `b181eb6a427678b2d374c98432abf114b0330693`
from the author's shared Port Menu repository. That development repository remains private;
no access to it is required. The source snapshot and its MIT/BSD notices are included here.

Verify with `python3 tools/check_port_menu.py`. File hashes and provenance are recorded
in `tools/port-menu-source.json`. To update, review and replace the complete snapshot,
refresh the manifest and run the shared-menu tests plus the port's integration checks.
Source archives include the menu without a submodule initialization step.
