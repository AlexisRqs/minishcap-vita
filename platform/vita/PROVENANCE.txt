sceAudioOut output. SDK and vita2d installation reused from the user's PMD port.
Platform3DS/TMC_3DS identifiers deliberately retain the upstream compact-console

disable libctru worker threads in mode1.c on Vita, using the serial renderer.

It is private build output, not a source-only public release. The runtime also
requires the user-supplied European cartridge image.

2026-10-29 source preparation: LiveArea PNGs removed from the tracked tree.
The ROM build renders title/forest frames in an isolated host directory and
composes shell assets locally using a stdlib PNG writer. Settings uses the
PSPSDK BSD font from Port Menu; no system font is required. No runtime engine
change or new hardware validation is implied. Historical PNG blobs remain in
the private development history; publish only the audited clean snapshot.
